# Usage Desk 0.1.1

Codex and Claude subscription usage, together in your Mac menu bar.

## Added

- Choose Codex or Claude when adding an account, with provider icons in the account picker.
- Claude Pro/Max five-hour and weekly quotas, remaining percentages, and reset countdowns.
- Connect the Claude CLI profile you already use, including a custom `CLAUDE_CONFIG_DIR`.
- Claude executable selection and automatic discovery of common/nvm installations.
- Version and build information in Preferences, plus a link to release notes.

## Fixed

- Preserve the macOS username needed for Claude's existing Keychain sign-in.
- Allow subscription-limit requests while disabling optional telemetry, error reporting, feedback, and updates.
- Package provider artwork with the app, including light/dark appearance support.
- Keep provider icons at native menu size instead of displaying full-size logos in the account picker.
- Confirm copied sign-in commands and links with a checkmark, stable button layout, retry feedback, and VoiceOver announcements.

## Installation and updating

This release is source only. The `install.sh` asset builds this exact source revision on your Mac;
`SHA256SUMS` covers the attached text assets. GitHub's Source code archives contain source, not a built app.
Requires macOS 14+, Xcode Command Line Tools with Swift 6+, and a signed-in Codex or Claude CLI.
The installer does not install those prerequisites or authenticate accounts.

To update an existing installation, quit Usage Desk and move only `~/Applications/Usage desk.app`
to Trash before rerunning the installer. Your account settings and CLI sign-ins are retained.
Do not remove your Codex or Claude configuration directories.

## Known limits

Claude uses an experimental CLI control protocol, which may change. Usage Desk sends no model prompts,
does not scan transcripts, and does not infer earned resets for Claude. Account selection changes the
usage being viewed; it does not switch your Codex or T3 login. Unreported limits remain unknown.
The locally built app is ad-hoc signed, not a notarized binary distribution.
