Before you install.

Is there a prebuilt app?

There is no prebuilt, signed installer yet. The source installer below downloads a pinned source revision, builds Usage Desk on your Mac, and installs it in your home Applications folder. macOS 14+ and Swift 6+ are required.

What do I need?

macOS 14+, Swift 6+, and either Codex CLI signed in with ChatGPT or Claude Code CLI signed in with Pro/Max. Chrome is optional for Codex sign-in.

Does it show every ChatGPT limit?

It shows the usage windows and earned resets returned by Codex. ChatGPT model or feature limits that Codex doesn’t expose won’t appear here.

Does it support Claude?

Yes. Choose Add account → Claude and connect your existing Claude Code CLI profile. Pro and Max usage windows are read without sending a model prompt. Claude’s experimental CLI protocol may require updates.

Can I monitor multiple Codex accounts?

Yes. Connect each OpenAI account separately, optionally choosing a Chrome profile for sign-in, then select whose Codex usage to view. Credentials stay on your Mac.

Does choosing an account switch Codex too?

It selects the usage you’re viewing in Usage Desk. Your active Codex desktop and CLI login stay unchanged.

Can Usage Desk redeem an earned reset?

Usage Desk displays the earned resets returned by Codex. It does not redeem them or run model requests.

Is it free?

Yes. The app and its original artwork are MIT licensed. OpenAI and Anthropic subscriptions are separate.

Install from source

Run in Terminal. Builds locally and installs into ~/Applications. No sudo required.

$curl -fsSL https://usage-desk.nikhilkr.in/install.sh | sh

Requires Xcode Command Line Tools with Swift 6 or newer. Inspect the script or follow the manual build instructions. At the end, choose to open Usage Desk, or open it from your home Applications folder.
